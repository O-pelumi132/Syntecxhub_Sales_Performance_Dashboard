#Sales Performance Dashboard
Internship project completed as part of the Syntecxhub Data Analysis Internship Program.


Project Overview
This project involved importing, cleaning and analysing a raw retail sales dataset to uncover key business insights. An interactive dashboard was built using Microsoft Power BI.

Tools Used
Microsoft Excel — data cleaning and analysis
Microsoft Power BI — interactive dashboard

Key Findings
Total Revenue: $2.26M across 9,799 orders
West region leads all regions with $710K in sales
Technology is the top performing category at 36.6% of revenue
Sales grew 20.3% from 2017 to 2018
Q4 drives 31% of total annual sales
Phones and Chairs are the top two sub-categories

Dataset
Superstore Sales Dataset sourced from Kaggle
